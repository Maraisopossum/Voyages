# Voyages

Carnets de voyage en pages statiques, publiés avec GitHub Pages.

- `madrid/` : Madrid à pied, 26 → 30 décembre 2026. Cartes OpenStreetMap (Leaflet) et itinéraires piétons calculés à l'ouverture de la page par le service OSRM de FOSSGIS.
- `reunion/` : La Réunion, Sud et Ouest, 1er → 14 août 2027. Carte Leaflet, routes et randonnées calculées à l'ouverture par OSRM, export GPX.
